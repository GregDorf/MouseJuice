# MouseJuice

**MouseJuice** — игра о мыши в постапокалиптическом государстве, где коты используют мышей для производства сока.

Главная задача игрока — выбраться с ужасной фабрики и выжить.

## О проекте

Изначально проект задумывался как **2D-платформер с боями**, исследованием уровней и попыткой сбежать с фабрики.

На текущем этапе реализованы только базовые элементы проекта:

* управление персонажем;
* базовая система перемещения;
* первоначальный интерфейс игры.

Интерфейс в дальнейшем планируется переработать, так как текущая версия оказалась неудобной.
